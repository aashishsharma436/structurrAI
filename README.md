# StructurrAI — Apple × Stripe redesign

A from-scratch React/Vite implementation of the StructurrAI marketing site.

## Design direction
- Apple-inspired typography, whitespace and premium product storytelling
- Stripe-inspired B2B hierarchy, technical data visualizations and developer-first CTAs
- Responsive navigation and layouts
- No dependency on the original site's frontend code

## Routes
/, /products, /hotel-mapping, /room-mapping, /website-grade-content, /resources, /api-access, /documentation, /faq, /about, /contact, /privacy, /terms plus article routes.

## Run
npm install
npm run dev

## Build
npm run build
